# Linux Basics

## What is Linux?

Linux is an open-source operating system used extensively in cloud computing.

## Advantages

- Open Source
- Secure
- Stable
- Lightweight
- Widely used in AWS, Azure, and GCP

## Linux vs Windows

| Linux | Windows |
|---------|---------|
| Free | Licensed |
| More Secure | More Malware Targeted |
| Better for Servers | Better for Desktop Users |
